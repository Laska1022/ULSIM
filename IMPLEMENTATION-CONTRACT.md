# Internal integration contract
Python >=3.11; package ulsim. CLI uses argparse. Dependencies paramiko>=3.4,<5 and zeroconf>=0.132,<1.
Target Python package is the same package, invoked python3 -m ulsim.target OP; OP inspect, identity, install, status, logs, health, services, configure, update, reboot. Requests JSON stdin, responses JSON stdout; failures JSON error and nonzero. Install starts detached systemd service, returns job_id. Target trusted paths /var/lib/ulsim, /etc/ulsim.
Hardware report schema: device_id, hostname, architecture (x86_64), boot_mode (bios|uefi), cpu dict, memory {total_bytes,available_bytes}, disks array {path,size_bytes,model,serial,wwn,transport,removable,installer,mounted,partitions}, network list, firmware dict, unknowns list. installer protection MUST derive ancestry of mounted live medium, fail closed if cannot determine.
Plan schema version=1, plan_id SHA256 canonical JSON of all fields except plan_id, device_id, hostname, distro=debian, suite=trixie, architecture=amd64, disk {path,size_bytes,serial,wwn}, boot_mode=bios|uefi, partition_table=gpt|mbr, profiles list of names (dns,fileserver,vpn,web,media), profile_config dict, admin_user=ulsim, authorized_key string. Strict validation and target hardware revalidation before erase. Approval token is plan_id, user approves explicit complete plan.
ulsim.hardware.collect() -> dict. ulsim.planning.create_plan(report,disk_path,hostname,profiles,authorized_key,partition_table="gpt",profile_config=None) -> dict; validate_plan(plan) -> dict or raises ValueError; ulsim.planning.recommend(report) -> dict.
ulsim.installer.start_install(plan,approval) -> dict; status() -> dict; logs() -> dict. ulsim.profiles.configure(names, config=None) -> dict; status(names=None) -> dict; verify(names) -> dict. Profiles operate on running installed Debian as root, invoked after reconnect.
Controller SSH uses paramiko with explicitly pinned ED25519 host key fingerprint. Image boots with public key and WiFi provisioned on separate FAT volume ULSIMCFG (second USB or writable appended partition); no password admin. Pair fingerprint displayed physical console or controller-generated per-device ED25519 host key provisioned securely over physical USB. Host keys copied into installed OS for trust continuity. mDNS _ulsim._tcp.local., SSH port 22, device_id persisted at /etc/ulsim/device-id.
Target installed account ulsim has password locked, authorized key, passwordless sudo for deterministic target module; controller RPC uses sudo -n /usr/bin/python3 -m ulsim.target OP. Target package installed under /usr/local/lib/python3.13/dist-packages/ulsim on Debian trixie (use sysconfig discovery).
Each agent owns assigned files only, coordinate API changes, do not commit until root integrates. Never claim unrun tests passed.
